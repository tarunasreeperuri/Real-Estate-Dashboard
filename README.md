# Real Estate Market Trends Dashboard

## 📊 Project Overview
An interactive Power BI dashboard designed to analyze real estate market trends and support investment and development decisions.

## 🎯 Objectives
- Analyze property prices and rental yields
- Compare market demand and supply
- Track key economic indicators
- Identify differences across major cities
- Present insights through interactive visualizations

## 🛠️ Tools & Technologies
- Power BI
- Microsoft Excel
- DAX
- Data Visualization

## 📈 Dashboard Insights
The dashboard includes:
- Average Property Price
- Rental Yield %
- Average Demand Index
- Property Price by City
- Rental Yield by City
- Average Annual Rent by City
- Demand & Supply Trends
- Interest Rate Comparison
- Employment Growth by City
- City-wise Market Summary

## 📌 Key Cities
Hyderabad | Bengaluru | Mumbai | Pune | Delhi
